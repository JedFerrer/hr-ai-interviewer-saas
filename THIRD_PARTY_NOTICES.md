## Provenance limits and rendered fonts

The shadcn tag above is a comparison reference, not a proven original extraction
revision. The Sonner issue reference does not establish a license for comment
prose. Provenance qualifications are recorded in the
[inventory](docs/third-party-inventory.md#provenance-qualifications).

The ten older DOCX files were reproduced with python-docx 1.2.0: all decompressed
ZIP members match. This supports the template notice above without asserting the
original generator version. Four portfolio fixtures reproduce byte-for-byte.

No font program is redistributed. A current Chromium probe uses Arial/ArialMT;
historical capture glyph identity remains unverified. Microsoft's
[Windows font output guidance](https://learn.microsoft.com/en-us/typography/fonts/font-faq)
distinguishes bitmap graphics from redistribution of font files. It is conditional
evidence for Windows-supplied fonts, not a certification of unidentified assets.
No additional font license or permission is invented here. Historical capture metadata remains incomplete; the inventory classifies this
as a nonblocking evidence gap for the selected raster images. No license for an
unidentified font program is asserted.
