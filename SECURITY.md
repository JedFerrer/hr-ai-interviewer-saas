# Security scope and reporting

This is a portfolio prototype for fictional local evaluation on Windows,
SQLite and one worker. It is not certified for hosted real-candidate operation.
See [data limits](docs/data-and-ai-limitations.md), [quality checks](docs/quality-checks.md)
and the [dependency review](docs/dependency-review.md).

The owner has decided not to establish a private security-reporting channel.
No reporting address or enabled GitHub private vulnerability reporting is claimed.
Selecting a contact is not a publication prerequisite.

Do not post sensitive findings, credentials, resumes, cookies, databases, raw
transcripts or token-bearing URLs in public issues, PRs or discussions. This
repository currently provides no confidential submission route. Public feedback
must omit sensitive evidence; no response-time commitment or bounty is offered.

Dependency remediation remains mandatory. No audit suppression, risk exception
or reduced severity threshold is accepted. Historical audit documents are not
current security assurances. Local verification does not establish production safety.
